# Chapter 5 Practice Pack

This folder contains exam-style, incomplete Java practice files based on Chapter 5 of the OCJP material.

## How to use this pack
1. Start with the beginner files and move upward.
2. Each file contains a short Oracle-style prompt and a TODO list.
3. Do not look at the solution until you have tried to complete it.
4. Focus on the exact rules from the chapter text: declarations, access modifiers, static, varargs, pass-by-value, autoboxing, and overloading.

## Progression
- Beginner: method declarations, local/final variables
- Intermediate: varargs, static members, initializers
- Advanced: pass-by-value, overloading, autoboxing
- Expert: subtle Oracle traps and tricky compile/runtime behavior
- Mock Exam: chapter-based practice questions
